# AIMS-mini – Use Case Diagram

## Actors
- Customer
- Store System

## Main Use Cases
- View DVD information
- Add DVD to cart
- Remove DVD from cart
- View cart
- Calculate total cost
- Search DVD by title

## Relationships
Customer interacts with the Store System to browse DVDs, manage the shopping cart, and search for products.

The system calculates the total cost based on the DVDs currently stored in the cart.
