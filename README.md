# AIMS-mini

Ứng dụng mẫu phục vụ thực hành Quản lý cấu hình phần mềm – IT3180.

## Project Information
- Repository: aims-mini-starter
- Course: IT3180 – Introduction to Software Engineering
- Language: Python
- Version Control: Git & GitHub

## Requirements
- Python >= 3.10
- Git >= 2.40

## Run Application

```bash
python main.py
```

## Run Tests

```bash
python -m unittest discover -s tests -v
```

## Branching Policy

- `master`: Main development branch.
- `feature/*`: Feature development.
- `topic/*`: Topic-based changes.
- `refactor/*`: Code refactoring.
- `bugfix/*`: Bug fixes.
- `release/*`: Release maintenance.
- `hotfix/*`: Production release fixes.
